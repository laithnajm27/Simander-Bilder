# Simander-Bilder

Dieses Repository ist als Bilder-Cloud für deine Webseite gedacht.

## So nutzt du es

- Erstelle Ordner wie `Album-1`, `Album-2`, `Album-3`.
- Lade deine Bilder in den gewünschten Ordner hoch.
- Wenn du einen Ordner umbenennen willst, musst du die Dateien in einen neuen Pfad verschieben.
- Danach kannst du die Bild-URLs direkt aus GitHub verwenden.

- `Album-1`
- `Album-2`
- `Album-3`
